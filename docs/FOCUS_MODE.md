# 专注核查（本地二开）

基于上游 SuperX 1.0.0，保留原来的自动核查模式。

- 在插件弹窗的「连接」下方切换「自动核查 / 专注核查」，下一行可设置停留秒数（0–30 秒）。改动立即保存，不改变连接来源、启用状态或其他设置。
- 专注模式在原生操作行添加 SuperX 标志和「审查」按钮，采用黑白配色与填充进度。点击立即核查；已有正文后显示「已审查」，宽度保持不变。
- 鼠标停留在帖子中时，按钮内部从左向右填充进度，不显示秒数。滚动时暂停并保留该帖进度，停止滚动后从已完成的进度继续；不同帖子分别计时。主动移开鼠标、切后台、打开媒体弹层或离开页面会取消当前计时；触屏不会触发悬停核查。
- 右栏只展示当前选中的帖子及结果，不重复显示蓝色原帖摘要。结果栏随帖子移动并避开搜索框，支持独立滚动和拖动滚动条。帖子离屏时隐藏结果栏，已开始的请求和结果仍保留，滚回后恢复，不重新请求。
- 再次点击已完成的帖子仅打开已有结果；「重新核查」才重新请求。专注模式不做失败后的自动重试，防止一次操作重复消耗额度。
- 未登录时，右栏显示登录提示，不跳转页面或发起推理；用户可点击提示中的设置入口完成登录。

本地安装时保持原加载目录和扩展 ID，不能把旧版 Python 桥接放回新版。验证使用 `npm run check`；测试覆盖后台请求门禁、连续悬停、离开/滚动/后台取消、重复点击去重、DOM 复用、单条侧栏、模式持久化以及并发保存设置。

选择记住登录时，访问令牌与刷新令牌都加密保存。重载丢失会话存储后，优先恢复仍有效的访问令牌；过期令牌、旧格式记录按原流程刷新。轮换中断或服务端撤销的凭据仍要求重新授权，不重复消费状态不确定的刷新令牌。

## 鬼扯分

评分与事实核查在同一次模型请求内生成，不为评分额外发起推理或搜索。

| 分数 | 等级 | 颜色 |
| --- | --- | --- |
| 0–20 | 基本可信 | 蓝色 |
| 21–40 | 轻度夸张 | 蓝青色 |
| 41–60 | 明显夸大 | 黄色 |
| 61–80 | 严重失实 | 橙色 |
| 81–100 | 高度误导 | 红色 |

标准规则：只判断可核查事实，不评判作者本人；以已检索的一手证据为基础，核心主张权重高于枝节。高分必须有具体、可引用的反证，不能因为语气激烈、观点不同、营销文案或未找到证据而打高分。证据不足或置信度低显示「待核实」；纯观点、玩笑、预测或无可核查事实显示「不适用」。这是模型参考判断，不是事实概率或法律结论。

评分规则位于 `extension/feed-core.js` 的 `REVIEW_SCORE_RULES`。模型在正文末尾附带受限评分记录，界面验证字段与分数范围后显示，记录本身不会出现在正文或历史阅读界面。旧回答、格式缺失或无效的评分显示「暂无评分」，不补造分数，也不自动重跑请求。
